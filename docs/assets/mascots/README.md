# Mascot reference photographs

Five photographs, one per companion species, taken by the project owner
(**Domezzxx**, ChivaGo / GFD Venture).

**© Domezzxx. All rights reserved.** This repository carries no `LICENSE`
file, so nothing here is granted to anyone by default — which is the correct
position for somebody's own photographs on a public repository.

## What they are for

Reference only. `apps/mobile/src/components/creature3d/companion-rig.ts`
follows this art as far as a rig can; the app draws every companion itself
from primitives and **ships none of these files**. Nothing in `dist-live` or
`dist-demo` contains a mascot bitmap — checked on 10 September 2026.

That is why they live in `docs/`, not in `apps/`.

## Metadata

All five carry **no EXIF, no GPS coordinates and no camera identifiers** —
verified 10 September 2026. A photograph on a public repository that still
holds the location it was taken at is a privacy leak whoever appears in it
never agreed to, and these do not have one.

## If any of this stops being true

Replace the credit line, not this file's existence. The project's rule is
that every photograph carries a real credit and a licence; a photograph
whose origin cannot be stated should be deleted rather than left unlabelled.
