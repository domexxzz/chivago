1. คลังฟุตเทจของจริง
--------------------

1.1 จอแอป - อัดจากเว็บเดโม https://chivago-demo-sigma.vercel.app
  - หน้าแรก: Healthy Score + ค่าอากาศ + จำนวนคนเช็กอินในหนึ่งชั่วโมง
  - แผนที่: เกาะจริง ความสูงจริง หมอกคลุมที่ยังไม่เคยไป เส้นเรือเฟอร์รี
  - ภารกิจ: บอร์ดภารกิจวันนี้ + หน้ารายละเอียด quest
  - กระเป๋าแต้ม: สองสกุลคนละสี (เขียว / ทอง)
  - ตลาด: ส่วนลดร้านในพื้นที่
  - สะสม: passport 77, เพื่อนร่วมเกาะในห้องสามมิติ, ไข่ที่ปิดผนึก, มาสคอต
  - ความปลอดภัย: หน้า SOS

1.2 จอคอนโซล host - เดโมไม่มี ต้องรันเครื่องตัวเอง
  เว็บเดโมไม่มีคอนโซล host, geofence จริง และการยืนยันจริง
  ต้องรัน: pnpm install -> pnpm seed -> pnpm api
  แล้วเปิด http://localhost:8787/console (seed พิมพ์ access key ให้ครั้งเดียว)
  อัดช็อต: คิวงานที่มีรูปหลักฐาน + ปุ่มอนุมัติ/ปฏิเสธในเฟรมเดียว

1.3 รูปสถานที่ที่มีไลเซนส์อยู่แล้วในระบบ (ใช้ได้ ต้องให้เครดิต)

             ย่านร้านค้าหน้าท่าล่าง

  โรงอาหารกลาง / สวนราชมงคล / น้ำพุราชมงคล มทร.ธัญบุรี
  หอประชุมใหญ่ + สนามอินทรีจันทรสถิตย์ มก. บางเขน

3. กฎการตัดสามข้อ
------------------
1. ช็อต 11-13 คือคลิปทั้งคลิป ห้ามย่อ ห้ามตัดสลับ
   ลำดับต้องเป็น หลักฐาน -> host กดอนุมัติ -> แต้มเขียวออก
   ถ้าเอาแต้มขึ้นก่อนการอนุมัติ สารของคลิปพังทันที
2. ตัดภาพบนช่องเงียบเท่านั้น ห้ามตัดกลางคำ
   (ช่องเงียบทุกจุดอยู่ในข้อ 0 แล้ว)
3. ช็อตที่ยาวเกิน 2.5 วิ ให้มีการเคลื่อนไหวในภาพ
   (นิ้วเลื่อน แผนที่หมุน ตัวเลขขึ้น) ไม่ใช่ภาพนิ่งค้าง


4. เสียง
---------
- คอมเพรสเซอร์เบา ratio ~3:1 แล้วนอร์มัลไลซ์ไปราว -16 LUFS
  คุม peak ไว้ที่ -1 dBFS (ตอนนี้ RMS -22 เบาเกินไปสำหรับใส่เพลง)
- เพลงประกอบวางไว้ราว -18 ถึง -20 dB ใต้เสียงพูด และ duck ลงอีก 3-4 dB
  ตอนช็อต 11-13 ให้คนฟังจับประโยคสำคัญได้
- ถ้าต้องให้พอดี 30.00 วินาทีเป๊ะ: ตัดจากช่องเงียบ ไม่ต้องแตะเสียงพูด
  หัวไฟล์ 0.30 -> 0.10, ท้ายไฟล์ 0.35 -> 0.15
  และหั่นช่อง 3.05 / 19.50 / 23.20 ลงเหลือ 0.85 วิ
  ห้ามแตะช่อง 15.65 เพราะเป็นจุดหายใจก่อนประโยคหักมุม

6. การอัดหน้าจอ
----------------
- ขนาด 1080 x 1920 (แนวตั้ง) สำหรับ Reels / TikTok / Shorts
- อัดจากเบราว์เซอร์โดยตั้ง device emulation ที่ 390 x 844 แล้วค่อยขยาย
- 60 fps ถ้าได้ เพราะมีช็อตแผนที่หมุนและแต้มวิ่ง
- ปิด notification บนเครื่องก่อนอัด
- อัดแต่ละช็อตยาวกว่าที่ต้องการ 2-3 วินาที เผื่อหาจุดตัด


7. ห้ามทำ
----------
- ห้ามใช้ภาพเจน AI หรือภาพสต็อกแล้วบอกว่าเป็นสมุย ศรีราชา หรือสีชัง
- ห้ามใช้ภาพป่าชายเลนที่อื่นใส่ชื่อท้องกรูด
  (รีโปตั้งใจปล่อยให้ที่นี่ไม่มีรูปเลย ดีกว่าใส่ภาพผิดที่)
- ห้ามครอปป้าย "ผังตัวอย่าง" หรือ "ภาพจำลอง" ออกจากช็อตใด
- ห้ามพูดหรือขึ้นข้อความว่า จองที่พักได้ จ่ายเงินได้
  หรือเล่นได้ทั้ง 77 จังหวัด - ทั้งสามข้อยังไม่จริง
  (เปิดจริง 2: สมุย + วิทยาเขตศรีราชา)
