เตรียมงานใหม่สำหรับเทคต่อไป
----------------------------
  node scripts/stage-filming-proof.mjs

หนึ่งครั้ง = หนึ่งงานรอตรวจ = หนึ่งเทค
สคริปต์จะพิมพ์ URL หน้าตรวจ device key และ link code ใหม่ให้ทุกครั้ง
และจะปฏิเสธการทำงานถ้า CHIVAGO_API ไม่ใช่ localhost


ถ้า API ดับ
-----------
  pnpm api

ถ้าลืม access key ของคอนโซล ให้หมุนใหม่:

  node -e "const{DatabaseSync}=require('node:sqlite');new DatabaseSync('apps/api/data/chivago.db').prepare('UPDATE hosts SET api_key_hash=NULL WHERE id=?').run('h-ku-chivago')"
  pnpm seed

seed จะพิมพ์คีย์ใหม่ให้ครั้งเดียว เก็บไว้ทันที (ระบบเก็บแต่แฮช)


สิ่งที่ควรรู้ว่าทำอะไรไปกับฐานข้อมูล
-------------------------------------
API มีการ์ดจริงว่าหลักฐานต้องส่งหลังเช็กอินอย่างน้อย 10 นาที
(QUEST_MIN_DWELL_MIN ใน packages/core/src/presence.ts)
เพื่อไม่ต้องรอสิบนาทีต่อหนึ่งเทค สคริปต์ย้อนเวลา arrived_at
ในไฟล์ SQLite ของเครื่องนี้ 16 นาที ไม่ได้แก้ซอร์สโค้ด
และไม่ได้ลดทอนกฎของตัวสินค้า - ถ้าเอาขึ้น pilot การ์ดยังทำงานเต็มที่

ฐานข้อมูลที่ถูกแตะคือ apps/api/data/chivago.db เท่านั้น
ถ้าต้องการล้างกลับเป็นของสะอาด: ลบไฟล์นั้นแล้วรัน pnpm seed ใหม่
