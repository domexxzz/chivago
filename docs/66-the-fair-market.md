# 66 — The fair market · ตลาดในงานเกษตรแฟร์ มทร.ธัญบุรี

หาร้านในงานจากชื่อ สินค้าที่ขาย หรือเลขล็อค แล้วกด *ดูบนแผนที่* ให้แผนที่บินไปที่ล็อคนั้น
สถานะ: **มีโค้ดแล้ว 6 ต.ค. 2569 · ใช้ผังตัวอย่าง** เพราะยังไม่มีผังจริงของงานเผยแพร่
(ค้นแล้วไม่พบข้อมูลสาธารณะเรื่องวันงาน สถานที่ หรือรายชื่อร้าน) ทุกหน้าที่แสดงงานนี้จึงเขียนว่า
*ผังตัวอย่าง · ยังไม่ใช่ผังจริงของงาน* ด้วยสีส้มแดงแบบเดียวกับของตัวอย่างอื่นในแอป

## ใช้งานยังไง

1. หน้าแรกของพื้นที่ มทร.ธัญบุรี มีการ์ด **ตลาดในงาน · งานเกษตรแฟร์ มทร.ธัญบุรี** อยู่บนสุด
   แท็บแผนที่ของพื้นที่นี้ก็มีปุ่ม *ค้นหาร้านและล็อค*
2. หน้าค้นหาพิมพ์อะไรก็ได้:
   - **สินค้า** เช่น `ทุเรียน`, `มะม่วง`, `กาแฟ`
   - **ชื่อร้าน**
   - **เลขล็อค** พิมพ์แบบไหนก็ได้: `a5`, `A05`, `A-05`, `a 05` คือล็อคเดียวกัน
   - หลายคำต้องตรงทุกคำ (`ไข่ เค็ม`)
   - ช่องว่างเปล่าแสดงทุกร้านเรียงตามผัง
   - ชิปโซนกรองเฉพาะโซน
3. ลำดับผลค้นหา: เลขล็อคตรงทั้งหมด → เลขล็อคขึ้นต้นด้วยคำค้น → ชื่อร้านขึ้นต้นด้วยคำค้น →
   ชื่อร้านมีคำค้น → สินค้ามีคำค้น → ชื่อโซน ล็อคว่างหาเจอด้วยเลขล็อคเท่านั้น
4. **ดูบนแผนที่** ส่งล็อคไปที่แท็บแผนที่ (แบบเดียวกับ *ดูเส้นทาง* ใช้แผนที่ตัวเดียว ไม่สร้างตัวที่สอง)
   - แผนที่บินไปที่ล็อค โชว์ทุกล็อคในงานเป็นจุดสีตามโซน ล็อคว่างเป็นจุดกลวง
   - ล็อคที่เลือกมีป้ายเลขล็อคและชื่อร้าน
   - แถบบนแผนที่บอกล็อคและปุ่มปิด
   - บนมือถือแอปซึ่งวิทยาเขตยังไม่มีแผนที่ แถบนี้คือคำตอบในตัวเอง
5. ร้านที่รับสั่งล่วงหน้าผ่านสั่งก่อน (`orderSlug`) มีปุ่ม *สั่งล่วงหน้า* เปิดหน้าสั่งของร้าน
   ลิงก์สร้างจาก slug ฝั่งนี้และผ่าน `isOrderLink` ก่อนแสดงปุ่ม (เหมือน docs/65)

## ข้อมูล

| ส่วน | ไฟล์ |
|---|---|
| ผัง ร้าน การค้นหา | `packages/core/src/fair.ts` — `FAIRS`, `fairLots`, `searchFair`, `fold`, `stepFrom`, `fairsIn`, `fairById`, `fairOrderUrl` |
| หน้าค้นหา | `apps/mobile/src/screens/FairScreen.tsx` (screen key `fair`) |
| การ์ดหน้าแรก | `HomeScreen.tsx` → `TopCards` / `FairCard` (ลอยทับขอบหัวแทนการ์ดคะแนนเมื่อพื้นที่มีงาน) |
| แผนที่ | `TerrainMap.tsx` (จุดล็อค + `flyTo`), `FairBanner.tsx`, `MapScreen.tsx`; สีโซน `fair-tones.ts` |
| ข้อความ | `strings.fair.*` สองภาษา |

ข้อมูลอยู่ใน core แบบเดียวกับ `PLACE_STALLS`: ไม่ต้อง migration ไม่มี API และเดโมแบบ static ใช้ได้ทันที
**งานไม่ใช่สถานที่** ล็อคไม่เข้า `/places` ไม่เข้าคะแนนพื้นที่ และไม่เข้าการ์ดสถานที่บนหน้าแรก

ผังเขียนเป็น **แถว** แบบผังงานจริง: แต่ละแถวระบุตำแหน่งล็อคแรก ทิศที่แถววิ่ง (องศาจากทิศเหนือตามเข็ม)
จำนวนล็อค และระยะห่าง ตำแหน่งที่เหลือคำนวณให้ ร้านเป็นรายการ `เลขล็อค → ชื่อ, สินค้า`

ผังตัวอย่างวางบนสนามกีฬาฝั่งใต้ (OpenStreetMap way 547540105 จุดกลาง 14.03194, 100.72414)
4 โซน (ต้นไม้ · ผลผลิต · อาหาร · ของแปรรูป) โซนละ 10 ล็อค ห่างกัน 10 เมตร ทางเดินห่าง 14 เมตร
ร้านเป็นคำอธิบายแบบกว้างๆ ของที่งานเกษตรขายกัน ไม่ใช่ธุรกิจจริง

## ใส่ผังจริง

1. ได้ผังงานจากผู้จัด → แก้ `rows` ใน `RMUTT_AGRI_FAIR`
   - จุดเริ่มแต่ละแถว: ใช้พิกัดจากแผนที่ หรือคำนวณจากจุดอ้างอิงด้วย `stepFrom`
   - ทิศของแถว จำนวนล็อค ระยะห่าง
   - `firstNumber` ถ้าโซนเดียวมีหลายแถว
2. ใส่ `stalls` ตามรายชื่อร้านที่ได้ล็อค ร้านไหนใช้สั่งก่อนก็ใส่ `orderSlug`
3. ใส่ `dates` และ `venue` ตามที่ประกาศ แล้วตั้ง `example: false`
4. เทสต์ (`packages/core/src/fair.test.ts`) ตรวจให้: ทุกล็อคอยู่ในพื้นที่ของงาน เลขล็อคไม่ซ้ำและอยู่ในรูป `A01`
   ร้านทุกร้านอยู่ในล็อคที่มีในผัง ล็อคละร้านเดียว และลิงก์สั่งก่อนผ่าน `isOrderLink`

## ยังไม่ได้ทำ

- แก้ผังผ่านหน้าเว็บ (ตอนนี้แก้ในโค้ดแล้ว deploy) ถ้าผู้จัดอยากแก้เองควรย้ายไปเก็บในฐานข้อมูล
- แตะจุดล็อคบนแผนที่เพื่อดูร้าน (ตอนนี้เลือกล็อคจากรายการ จุดบนแผนที่ไม่รับการแตะ)
- งานที่ ม.เกษตรศาสตร์ บางเขน (พื้นที่ `ku-bangkhen` มีอยู่แล้ว) ใช้โครงเดียวกันได้ เพิ่มเป็นอีกงานใน `FAIRS`
